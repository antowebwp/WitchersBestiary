## Gameplay
Sneak-interact with an existing Arcane Merchant (village or wandering) in Survival to open the organizer. Ordinary fighter invitations are unchanged. Select Village/City/Championship, Enter, then Continue with both hands empty. The existing rebindable duel-menu key (O by default) opens the tournament menu during a bout for abandonment. RU/EN interface includes linear rounds, existing opponent tiers, progress, result history and titles.

Village3/150, City4/400, Championship5/1000; previous championship unlocks the next category. Opponents use existing novice/experienced/champion entities, models, animations and AI. Higher categories face more experienced/champion opponents rather than inflated new health multipliers. Rewards exceed isolated12/28/60-crown NPC bouts but have a separate72000-tick personal/category cooldown. Training retains titles/progress without a second paid victory during cooldown.

The server scans only nearby loaded space8–32 blocks from the organizer, with±3 height adjustment. It requires an outdoor7x7 level supported clearing, three blocks clearance, no fluids/fire/magma/powder snow/wither roses, world-border clearance and no living occupants. Full12-block official-bout boundaries reserve25 blocks between arena centers. No blocks are built/broken and no persistent chunk tickets are created. Failure leaves the round resumable and asks the player to find another open organizer location.

Tournament bouts are ordinary FistFights sessions. Existing server damage/item/sign/sorcery/duel restrictions, virtual health, stamina and nonfatal KO handling remain authoritative. Intermediate rounds suppress ordinary NPC prizes. Completion removes the temporary opponent and releases the arena. The existing movable/scalable Combat HUD displays opponent, localized category/round, stamina/virtual health and combat state; no second HUD is created.

## Persistence and security
UUID-personal PersistentState stores unlock/title bits, current category/round, last result and paid-until timestamps. Between rounds survives logout/restart. Disconnect/surrender/dimension/boundary interruption during a bout loses the tournament and preserves previous round history. Server stopping cancels live bouts; unexpected restart cancels persisted fighting rows and removes tagged orphan opponents when loaded. Other ledgers/inventory/XP/actual player health are untouched.

Only a registered live round can finish once. A champion reserves the existing FistRewards pending payment in the same server-thread transition as title/cooldown, then claims through existing wallet/physical-crown planning. Full inventory retains pending money. There is no client completion/reward request. Menu requests use a rotating random per-player token; source entity, distance, world, active session and arena reservations are checked server-side. Replayed actions cannot create another opponent or paid completion. Durability follows existing normal world/player saves, without a new cross-file crash-transaction guarantee.
