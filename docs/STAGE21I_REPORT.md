# Stage21I — Grimoire, Icy Grasp and universal signs

Implementation checkpoint; native two-client final campaign in progress. No release/push.

- Existing Bestiary learning retained. New separate Survival-craftable Grimoire with original deterministic9-volume book/64px atlas, RU/EN Patchouli pages, Learn/Cast widgets and one real spell. Optional rebindable sorcery key is unassigned by default, so no foreign key is changed. Default casting is the book Cast button, aimed at a visible enemy; signs retain R/G.
- Icy Grasp: server ray selects hostile LivingEntity within12 blocks before the nearest block,6 base damage,60 ticks Slowness IV (20 for large enemies),160 tick cooldown,1 amethyst shard consumed only on successful damage. Free personal learning, separate persistent ledger/cooldown, no sign concentration or parallel mana system. Shared target recovery prevents overlapping caster stun-lock. No block changes: bounded snow/ice particles and six lightweight client ice crystals melt after the short effect.
- Optional Spell Power1.4.6 API is loaded lazily via public SpellSchools.FROST / SpellPower / SpellDamageSource; damage6+0.5 frost power, capped12, otherwise standalone6. Spell Engine1.9.9 exposes item/exhaustion costs, not a mandatory shared mana pool; WB uses the supported vanilla item-cost model without modifying its mechanics, containers or keybinds. Either/both optional mods may be absent.
- Both book networking and casting are server-authoritative, session/sequence/rate limited, inventory/learning/cooldown/ray/hostility/PvP/fist checked. Existing sword enchantment hooks require actual PLAYER_ATTACK; sign and sorcery damage cannot enter that path.
- Sign targeting now accepts generic Monster/spawn-group hostility and actual hostile Mob relationships, protecting teammates, merchants, passive creatures, tameable/horse and player-owned pets, creative/spectator players and official fist fighters. No entity-type whitelist. Neutral angry mobs require actual aggression. Axii suspends ordinary Mob AI without deleting goals or toggling foreign AI flags; native immunity hooks remain authoritative, and a datapack-extensible control_immune tag excludes dragon/wither/warden by default.
- Fixed sign values once: Igni4.8 (was4), Aard1.15 (was1), unchanged3s ignition; knockback now honours native resistance with reduced large-target strength; Quen10 HP with no refresh while its finite shield remains active; Yrden1 magic HP per40 ticks per entity, globally deduplicated across overlapping player traps and reduced boss slow. No Spell Engine mana or progressive-difficulty changes.
